# Working notes (Ukrainian)

This directory contains the authors' internal working notes, written in
Ukrainian while the experiments were being developed. They are kept for
transparency about how the study evolved and are **not** part of the
peer-reviewed analysis.

- `EXPERIMENT_REPORT_UK.md`: exploratory E1–E5 run.
- `FOLLOWUP_EXPERIMENT_REPORT_UK.md`: exploratory E6–E10 follow-up.
- `DIAGNOSTIC_PROTOCOL_UK.md`: internal protocol for the second-stage
  diagnostics E11–E15, written before that run.
- `DECISIVE_DIAGNOSTIC_REPORT_UK.md`: first internal summary of E11–E15.

Some terminology in these notes predates the published analysis. In
particular, "preregistration" in `DIAGNOSTIC_PROTOCOL_UK.md` refers to an
internal protocol fixed before the second-stage run; it was **not**
registered externally, and the same official test split had already been
inspected during the exploratory stage. Likewise, "confirmatory" in these
notes denotes the predefined primary contrasts, not independent
confirmation. The paper describes all results as controlled evidence within
a previously inspected test split, and its wording and numbers take
precedence over these notes.
